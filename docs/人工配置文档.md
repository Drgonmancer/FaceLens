# FaceGuard 人工配置文档

> **版本**：V1.1 · **更新**：2026-05-28  
> 本文说明部署后需人工修改的配置项，不含自动安装脚本内部逻辑。

---

## 1. 配置文件总览

| 文件 | 路径 | 用途 |
|------|------|------|
| **数据库配置** | `server/config.ini` | MySQL 连接（**必配**） |
| 配置模板 | `server/config.ini.example` | 复制后修改 |
| 配置向导 | `server/setup_config.py` | 交互式生成 `config.ini` |
| Django 设置 | `server/dj2/settings.py` | 框架级配置（一般不改） |
| 业务阈值 | 数据库表 `systemconfig` | `face_threshold` 等 |

> **安全提示**：`config.ini` 含数据库密码，已加入 `.gitignore`，**切勿提交到公开仓库**。  
> 若修改过 `util/opencv_face.py` 中的数据库连接，请统一改为读取 `config.ini`，避免密码硬编码。

## 2. 数据库配置（config.ini）

### 2.1 文件格式

```ini
[sql]
type = mysql
host = 127.0.0.1
port = 3306
user = root
passwd = 你的MySQL密码
db = cl3286667
charset = utf8
```

### 2.2 配置步骤

**方式一：配置向导（推荐）**

```bash
cd server
python setup_config.py
```

按提示输入主机、端口、用户名、密码、库名；向导会测试连接并写入 `config.ini`。

**方式二：手动复制**

```bash
copy config.ini.example config.ini   # Windows
```

编辑 `passwd`、`host`、`db` 等字段。

### 2.3 初始化数据库

```sql
CREATE DATABASE IF NOT EXISTS cl3286667
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

```bash
mysql -u root -p cl3286667 < sql/cl3286667.sql
```

### 2.4 验证连接

```bash
cd server
python check_mysql.py
```

启动服务时控制台会打印：`mysql 127.0.0.1 3306 root **** cl3286667 utf8`，表示已加载配置。

## 3. 人脸识别参数

### 3.1 匹配阈值 face_threshold

| 属性 | 说明 |
|------|------|
| 存储位置 | 表 `systemconfig`，键名 `face_threshold` |
| 取值范围 | **40～100**（整数） |
| 默认值 | **70** |
| 含义 | LBPH 换算后的匹配分数 ≥ 阈值时判定为同一人 |

**修改方式：**

1. **管理界面**：系统设置 → 保存阈值（调用 `POST /cl3286667/face/saveThreshold`）
2. **API**：`POST /cl3286667/system/config/set`，body：`{"configkey":"face_threshold","configvalue":"75"}`
3. **SQL**：
   ```sql
   UPDATE systemconfig SET configvalue='75' WHERE configkey='face_threshold';
   ```

**调参建议：**

| 现象 | 建议 |
|------|------|
| 误识率高（陌生人被认成注册用户） | **提高**阈值（如 75～85） |
| 本人经常登录失败 | **降低**阈值（如 55～65），并增加采集样本 |
| 光线差、摄像头模糊 | 先改善采集质量，再调阈值 |

### 3.2 采集质量门槛

在 `util/opencv_face.py` 中，注册时质量分 **< 40** 会拒绝入库。若需调整，修改：

```python
if quality < 40:  # 可改为 30 或 50
    return False, f"图片质量过低..."
```

### 3.3 LBPH 与 Haar 参数（高级）

文件：`server/util/opencv_face.py`

| 参数 | 默认值 | 说明 |
|------|--------|------|
| LBPH `radius` | 1 | LBP 半径 |
| LBPH `neighbors` | 8 | 邻域点数 |
| 检测 `scaleFactor` | 1.08 | 多尺度缩放步长 |
| 检测 `minNeighbors` | 7 | 候选框合并强度 |
| 人脸裁剪尺寸 | 200×200 | 灰度图统一大小 |

修改后需重新采集样本或删除 `templates/file/face_train/` 下对应用户目录后重采。

## 4. 目录与文件存储

启动时工作目录应为 **`server`**（`manage.py` 所在目录）。

| 路径 | 内容 |
|------|------|
| `templates/file/face_train/{user_id}/` | 用户人脸样本 `.pgm` / `.jpg` |
| `templates/file/face_train/lbph_model.yml` | LBPH 模型文件 |
| `templates/file/face_train/label_map.json` | 标签 ID → 用户 ID 映射 |
| `templates/file/login_faces/` | 登录/陌生人抓拍图 |
| `templates/client/` | 用户端 HTML 页面 |
| `templates/manage/` | 管理端静态资源（build 后） |

**备份建议**：定期备份 `face_train` 目录与 MySQL 库 `cl3286667`。

**清空某用户人脸**：

- 管理端删除账号，或  
- API：`POST /cl3286667/face/register`，`action=delete_all`，`userid=用户ID`

## 5. 服务与网络配置

### 5.1 监听地址与端口

```bash
python manage.py runserver 0.0.0.0:8000
```

| 配置项 | 文件 | 说明 |
|--------|------|------|
| `ALLOWED_HOSTS` | `dj2/settings.py` | 当前为 `["*"]`，生产环境应改为具体域名 |
| `DEBUG` | `dj2/settings.py` | 生产环境务必设为 `False` |
| Session 有效期 | `SESSION_COOKIE_AGE` | 默认 1209600 秒（14 天） |

### 5.2 跨域（CORS）

`dj2/settings.py` 中已启用：

```python
CORS_ALLOW_CREDENTIALS = True
CORS_ORIGIN_ALLOW_ALL = True
```

若 Vue 管理端独立端口访问，一般无需额外配置；生产环境建议限制 `CORS_ORIGIN_ALLOW_ALL`。

### 5.3 项目上下文路径（schemaName）

数据库名即 URL 前缀：`/cl3286667/`。修改库名后需同步：

1. `config.ini` 的 `db`  
2. `sql/cl3286667.sql` 或新建库并迁移  
3. 前端页面中的 `BASE` 路径（如 `templates/client/index.html`）

## 6. 认证与白名单

中间件：`xmiddleware/xauth.py`

**POST 免 Token 接口**（路径包含即放行）：

- `register`、`login`、`faceLogin`
- `qualityCheck`、`update`（部分更新）
- 白名单列表中的 `file/upload` 等

**GET 请求**：静态资源、`/client/`、`/manage/`、`detail` 等路径免认证。

**需登录接口**：请求头携带：

```
Token: <Base64编码的认证串>
```

或：

```
Authorization: Bearer <同上>
```

Token 由登录接口返回，详见 [后端 API 接口文档](./后端API接口文档.md)。

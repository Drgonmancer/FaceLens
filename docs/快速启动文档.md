# 快速启动

> 项目结构：`client/` 管理端 · `server/` 后端 · `docs/` 文档

## 环境要求

- Python 3.8+、MySQL 5.7+/8.0、现代浏览器（摄像头可选）

## 方式一：一键安装（Windows）

1. 右键根目录 `install.bat` → **以管理员身份运行**
2. 按提示配置 MySQL
3. 浏览器打开 http://localhost:8000/cl3286667/

Linux/macOS：`chmod +x install.sh && ./install.sh`

## 方式二：手动启动

```bash
# 1. 配置数据库
cd server
copy config.ini.example config.ini    # Windows
python setup_config.py

# 2. 初始化库（首次）
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS cl3286667 DEFAULT CHARSET utf8mb4;"
mysql -u root -p cl3286667 < sql/cl3286667.sql

# 3. 依赖与启动
pip install -r requirements.txt
python manage.py runserver 0.0.0.0:8000
```

或双击 `server/start_server.bat`。

## 访问地址

| 入口 | URL |
|------|-----|
| 用户端 | http://localhost:8000/cl3286667/ |
| 管理端（Vue 构建后） | http://localhost:8000/cl3286667/manage/ |

默认管理员：`admin` / `admin`

## 可选：Vue 管理端开发

```bash
cd client
npm install
npm run serve
```

构建部署：`npm run build` → 输出到 `server/templates/manage/`

## 首次使用

注册 → 密码登录 → 个人中心采集 3～6 张人脸 → 退出后「人脸识别登录」

## 常见问题

- **摄像头**：使用 `http://localhost` 访问并允许权限
- **MySQL**：确认服务已启动，`server/config.ini` 密码正确 → 见 [人工配置](./人工配置文档.md)
- **识别失败**：改善光线与正脸角度，或调低 `face_threshold`（40～100）

更多见 [人工配置文档](./人工配置文档.md)、[API 文档](./后端API接口文档.md)。
